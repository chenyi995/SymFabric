Strict FP32, TF32 off, batch 64, three disjoint batches, 20 completed timing
repetitions per variant/batch, unchanged 20-round budget. Corrected compiled /
complete graph / best tested latency means of batch medians:

| Dataset | Compiled | Complete graph | Best tested | Ratio vs graph |
|---|---:|---:|---:|---:|
| Family | 52.396 ms | 46.092 ms | 14.975 ms | 3.08x |
| WN18RR | 97.978 ms | 95.280 ms | 24.623 ms | 3.87x |

Actions, retained state at each round, final success/depth, and repeated output
hashes match the corrected native controls. Valid-logit roundoff has an explicit
tolerance. Both datasets need the stable first-K candidate correction; broader
WN18RR testing found the upstream scatter race after the first batch had passed.
The old WN18RR ~112 ms result is not the optimized comparison denominator.

Nsight Systems jobs 220690 / 220691 attribute 62.0% / 68.1% of captured kernel
time to the environment. Selected Nsight Compute jobs 220692 / 220693 identify
high-bandwidth invalid-state writes. These are different timing quantities
from unprofiled complete latency. Dense fact-state intermediates are still
built before final packing, so more GPU work reduction remains possible.

Checkpoints use short profiling training, not paper-converged models. KG REASON
mapping offloads final dot products only. Its scheduler is uncalibrated; modeled
serialization and bank imbalance do not establish limitations of original
REASON. No first-order hardware transition engine or calibrated RTL is delivered.
No energy, area or universal-prover benefit is established.
