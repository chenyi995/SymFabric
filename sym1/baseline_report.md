# sym1 local baseline and bottleneck report

This report is generated by `scripts/report_baselines.py` from explicit raw-run directories. CPU times are measured on this host; simulated cycles are measurements of upstream models, not silicon. All ratios are derived with the formulas below. No GPU or sym1 accelerator speedup is claimed.

## Interpretation and remaining evidence

The measured bottlenecks are configuration-dependent: synchronization/priority-bucket scheduling in the profiled CPU SSSP case; matrix-scan work and temporary tensors in CPU DP; indexed recursive evaluation and small-task overhead in Datalog; coordinate/token processing in SAM; and narrow-query utilization in the dense array model. They do not establish a single universal memory bottleneck. Bucket tuning and the DP schedule ablation are software improvements and cannot be credited to sym1.

The literature audit is in `literature_review.md`. GPU software characterization remains unavailable on this host. REASON/Revet/Capstan are not reproduced by the available generic simulators; DPU-v2 RTL, GraphLily, Ramulator and STONNE are cloned but not executed in this report. No cycle-level sym1-versus-baseline result, PE synthesis or end-to-end neuro-symbolic speedup has been obtained. The original closed-form model is kept distinct from the upstream simulator measurements.
